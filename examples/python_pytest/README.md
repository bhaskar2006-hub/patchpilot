# PatchPilot Example: Python Pytest Self-Healing

This example demonstrates how PatchPilot diagnoses and automatically repairs a broken division error.

## Try It

1. Change into this directory:
   ```bash
   cd examples/python_pytest
   ```

2. Run Pytest directly to see the failure:
   ```bash
   pytest
   ```

3. Run PatchPilot to autonomously heal it:
   ```bash
   patchpilot heal
   ```

4. Check git diff to inspect the surgical repair generated by your local SLM:
   ```bash
   git diff calc.py
   ```
